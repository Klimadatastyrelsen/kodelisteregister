[#description]
== Beskrivelse
{doctitle}s kodelister er kodelister med de tilladte værdier for attributter på GeoDanmark Vektors objekttyper, fx bygninger, vejmidter, vandløbsmidter og arealer. Nogle kodelister er generelle og bruges på tværs af alle objekttyper, fx objektstatus og geometristatus. Andre er objekttypespecifikke og gælder kun for én eller få objekttyper, fx bygningstype og vejkategori. Listerne er fastsat i GeoDanmark-specifikationen og sikrer, at objekterne registreres ens i hele landet.
